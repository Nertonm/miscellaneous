# miscellaneous

Este repositório contém arquivos e scripts variados, reunidos para diferentes propósitos de testes, estudos e utilidades cotidianas. Não há um tema central, mas sim uma coleção de recursos que podem ser úteis tanto para referência quanto para experimentação.

## Estrutura atual do repositório

- `README.md`  
  Este arquivo de descrição do projeto.

- `portfolio/`  
  Projeto web com demonstração 3D interativa ("Hire Me"), contendo arquivos HTML, CSS, JavaScript, modelos 3D (`abacate.glb`) e áudio.

- `configs/`  
  Configurações de sistema e ambiente:
  - `vim/.vimrc`: Arquivo de configuração e atalhos para o editor Vim.
  - `gentoo/`: Scripts e configurações relacionadas ao Gentoo Linux.
  - `hyprland-dotfiles/`: Repositório de dotfiles do ambiente desktop Hyprland.

## Objetivo

O repositório serve como um espaço para armazenar e compartilhar arquivos diversos que podem ser úteis no dia a dia de desenvolvimento, aprendizado ou customização de ambientes.

## Como contribuir

Sinta-se livre para abrir issues ou pull requests caso queira sugerir melhorias, adicionar utilitários ou compartilhar experiências relacionadas ao conteúdo deste repositório.
