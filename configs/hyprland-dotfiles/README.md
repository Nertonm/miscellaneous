# Hyprland Dotfiles

Este repositório contém as configurações e scripts do meu ecossistema Hyprland e ambiente CLI.

## Componentes

- **Compositor:** Hyprland
- **Barra de Status:** Waybar
- **Lançador de Apps:** Wofi
- **Terminal:** Kitty
- **Notificações:** Dunst
- **Monitor de Sistema:** Btop
- **Shell:** Fish / Bash / Zsh
- **Multiplexador:** Tmux
- **Gerenciador de Arquivos CLI:** Yazi
- **Bluetooth CLI:** Bluetuith
- **Scripts:** Localizados em `.local/bin/` (Controle de áudio, bateria, modo jogo, etc.)
- **Extra:** MangoHud (Overlay de jogos), Fontconfig, Configurações de VIM e Git.

## Estrutura

- `.config/`: Pastas de configuração de cada aplicação.
- `.local/bin/`: Scripts de sistema e automação.
- Arquivos na raiz: `.bashrc`, `.zshrc`, `.vimrc`, `.gitconfig`, `.tmux_cheatsheet.sh`.
